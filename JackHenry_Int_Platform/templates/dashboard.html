About This Platform

This platform integrates with Jack Henry's Garden test environment to sync customer, account, and beneficiary data using their Consumer API and jXchange services.

Features:

  • OAuth 2.0 + OpenID Connect authentication
  • Consumer API integration for accounts and transactions
  • Database storage of customer profiles, accounts, and beneficiaries
  • JSON export functionality for all data
  • Sync activity logging and monitoring

Next Steps:

  • Configure your Jack Henry API credentials in the Configuration page
  • Click "Authenticate & Sync New Customer" to connect a test user from Garden
  • View synced data in the Customers, Accounts, and Beneficiaries pages
  • Export data as JSON to use in other platforms (e.g., creating matching death certificates and claim forms)
