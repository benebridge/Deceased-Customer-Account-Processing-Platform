How to Get API Credentials

  1. Go to jackhenry.dev
  2. Create a developer account or sign in
  3. Navigate to your developer dashboard
  4. Create a new application or use an existing one
  5. Copy your Client ID and Client Secret
  6. Set up the redirect URI: http://localhost:5011/callback
  7. Save the scopes: openid profile email phone address offline_access banno
  8. Paste your credentials above and click Save Configuration
